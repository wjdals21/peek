## 2026-05-19

### 기술 방향 재정리

**작업 내용**

- 프로젝트 구현 방향을 React/Vite + Tailwind CSS + LocalStorage로 확정
- 기존 문서에 남아 있던 Vanilla JS, Tailwind CDN, `js/*.js` 기준 작업 항목을 현재 코드 구조에 맞게 갱신
- MVP 데이터 저장 범위를 LocalStorage로 명확히 하고, Supabase/DB 연동은 이후 단계로 보류
- AI 호출은 API 키 보호를 위해 Express 서버를 통한 호출 구조로 정리

**수정된 문서**

| 파일 | 내용 |
|---|---|
| `docs/PRD.md` | 기술 스택과 48시간 개발 순서를 React/Vite 기준으로 수정 |
| `docs/WORK.md` | 예정 작업 경로와 결정 사항을 `src/*`, `server.js` 기준으로 수정 |
| `docs/HISTORY.md` | 기술 방향 변경 이력 추가 |
| `docs/CLAUDE_project.md` | 프로젝트 지침을 React/Vite + Tailwind CSS + LocalStorage 기준으로 수정 |

**주요 결정 사항**

- 기술 스택: React/Vite + Tailwind CSS + LocalStorage
- 상태 관리: React Context + 커스텀 훅
- 데이터 저장: MVP에서는 LocalStorage만 사용
- AI 연동: Claude API 키 보호를 위해 Express 서버를 통해 호출

### 최종 기획문서 기반 방향 보정

**작업 내용**

- `Peek_기획문서_최종수정본.docx` 내용을 반영해 서비스 표현을 AI 스크랩 저장소에서 AI 리서치 보관함/콘텐츠 초안 생성 흐름으로 보정
- 링크별 중복 점수 중심 UI를 제거하고, 콘텐츠 생성 결과에서 중복 제거율을 설명하는 구조로 변경
- 콘텐츠 생성 프롬프트를 링크 단위 제외가 아닌 정보 포인트 단위 병합/고유 정보 보존/출처 표시 중심으로 수정
- 콘텐츠 생성 가능 기준을 링크 3개 이상에서 2개 이상으로 조정

**수정된 파일**

| `server.js` | Claude 콘텐츠 생성 프롬프트와 출력 JSON을 최종 기획문서 기준으로 변경 |
| `src/components/content/ContentDetail.jsx` | 중복 제거율, 병합된 반복 정보, 보존된 고유 정보, 제거된 노이즈, 최종 초안 표시 |
